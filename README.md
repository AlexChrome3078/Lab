## Запуск

1. Открой Visual Studio и создай консольный проект на C.
2. Добавь файл `main.c` из нужной папки.
3. Запусти программу.
4. Чтобы проверить другую часть работы, измени вызовы функций в `main()`: раскомментируй нужную функцию и при необходимости закомментируй текущую.

Каждая лабораторная находится в отдельной папке и содержит собственный файл `main.c`.
